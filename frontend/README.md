# Frontend

React + TypeScript UI for Blue River Grid Intelligence (Vite). See the root [README](../README.md) and [docs/development.md](../docs/development.md).

```bash
npm ci
npm run dev      # proxies /api to http://127.0.0.1:8000
npm test         # Vitest + Testing Library
npm run lint     # oxlint
npm run build    # outputs to ../backend/static (served by FastAPI)
```
